## Architecture

Federated monorepo. Each platform is an independent repo that connects to shared infrastructure.

```
xenogenisys/
├── packages/          ← Shared: ARBI, types, DB, auth, UI
└── apps/              ← Each platform as a git submodule
```

See [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) for full technical details.

## The Philosophy

ARBI — Artificial Biological & Reconnaissance Intelligence — was conceived before large language models existed. Built from the conviction that intelligence, artificial and biological, must evolve together or not at all.

The Third Emergent: something that is both human and artificial intelligence, yet neither. A co-evolutionary relationship where each gives to the other what it lacks — and what emerges from that exchange is greater than either alone.
